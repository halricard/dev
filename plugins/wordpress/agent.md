## WordPress

- WP-CLI is available through `dev exec wp <command>`. Run it from the project root.
- Useful commands: `dev exec wp plugin list`, `dev exec wp theme list`, `dev exec wp option get siteurl`, `dev exec wp cache flush`, `dev exec wp rewrite flush`, `dev exec wp user list`.
- Change URLs with `dev exec wp search-replace <old> <new> --dry-run` first. Take a `dev snapshot` before the real run.
- `wp-config.php` is generated by `dev`. Keep the `DB_*` constants unchanged.
- WP-Cron runs from `dev.schedule`. Do not add a second cron trigger.
- Add `define( 'WP_DEBUG_LOG', true );` to `wp-config.php` only when needed, then read errors with `dev logs`.
