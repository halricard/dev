## WordPress

- WP-CLI is available through `dev exec wp <command>`. Run it from the project root.
- Useful commands: `dev exec wp plugin list`, `dev exec wp theme list`, `dev exec wp option get siteurl`, `dev exec wp cache flush`, `dev exec wp rewrite flush`, `dev exec wp user list`.
- Change URLs with `dev exec wp search-replace <old> <new> --dry-run` first. Take a `dev snapshot` before the real run.
- `wp-config.php` is generated by `dev`. Keep the `DB_*` constants unchanged.
- WP-Cron runs from `dev.schedule`. Do not add a second cron trigger.
- Add `define( 'WP_DEBUG_LOG', true );` to `wp-config.php` only when needed, then read errors with `dev logs`.

### WordPress tests

- `dev test phpunit <plugin-or-theme-dir> [args]` runs a plugin's or theme's PHPUnit integration tests with the official WordPress test library, in a separate `_tests` database. The directory needs a `phpunit.xml` or `phpunit.xml.dist` and PHPUnit in its `vendor/`. Example: `dev test phpunit wp-content/plugins/my-plugin --filter=test_settings`.
- `dev test e2e [dir] [args]` runs Playwright end-to-end tests (`@playwright/test`) against {{URL}}. It creates a temporary admin user for the run and passes it as `WP_USERNAME` and `WP_PASSWORD` (the variables `@wordpress/e2e-test-utils-playwright` reads), with `WP_BASE_URL` set to the site.

### WordPress documentation

- `/websites/developer_wordpress_reference_functions` — the official function reference.
- `/websites/developer_wordpress_reference_hooks` — action and filter hooks.
- `/websites/developer_wordpress_reference_classes` — core classes (`WP_Query`, `WP_REST_Controller`, `wpdb`).
- `/websites/developer_wordpress_plugins` and `/websites/developer_wordpress_themes` — the Plugin and Theme Handbooks: security, nonces, sanitizing and escaping, settings, REST API, i18n.
- `/wordpress/gutenberg` — the block editor: `block.json`, block APIs and `@wordpress/*` packages.
- `/wp-cli/handbook` — WP-CLI commands.
- Check the "Since" and deprecation notes against the version above before you use a function or hook.
