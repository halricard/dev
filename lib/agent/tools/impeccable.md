### UI direction: impeccable

- Only when the feature has a user interface. In design, run `/impeccable shape` for each new screen. In verify, run `/impeccable audit` and `/impeccable critique` on the changed screens, then fix what they find with `harden`, `clarify` or `adapt`.
- The interface must look like part of {{APP_TITLE}}: follow the UI notes below. Do not use the commands that restyle it (`bolder`, `colorize`, `overdrive`).
- If the project has no `PRODUCT.md`, run `/impeccable init` before the first `shape`.
