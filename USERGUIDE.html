dev

Ambiente de desenvolvimento PHP e Node.js para WSL2 e Linux, sem Docker e modular por plugins.

1. Visão Geral e Arquitetura

O dev foi projetado para alta velocidade, determinismo e simplicidade operacional:

  • Core Principal: Instala PHP 8.5 estático, Nginx 1.30 estático, MySQL 8.4 LTS, Node.js LTS, Composer, Mailpit, Adminer e autoridade local mkcert.
  • Arquitetura de Plugins: Aplicações pesadas (WordPress, Laravel, Moodle) não poluem o core. Instale incrementalmente apenas o que você precisa.
  • Sem Docker nem systemd: Inicialização instantânea em segundos, baixo consumo de memória e supervisão inteligente de portas.

2. Instalação e Gerenciamento do Ambiente

na máquina

$ ./dev install ▸ COMPONENTES DO CORE ✔ PHP 8.5.11 ✔ nginx 1.30.5 ✔ MySQL 8.4.9 ✔ Node.js LTS ✔ Composer, Mailpit, Adminer e mkcert ✔ Ambiente pronto em ~/.dev

3. Sistema Modular de Plugins

Gerencie o ciclo de vida dos plugins com facilidade:

na máquina

$ dev plugin list ✔ wordpress WordPress instalado ○ laravel Laravel disponível ○ moodle Moodle disponível $ dev plugin install moodle ✔ plugin "moodle" instalado com sucesso $ dev plugin remove laravel ✔ plugin "laravel" removido com sucesso

4. Guia Rápido: Moodle

Fluxo de trabalho prático do Moodle com layout seguro de diretórios (app/ e data/):

na máquina

$ dev plugin install moodle $ dev new moodle meu-ead ✔ Moodle pronto em https://meu-ead.localhost → docroot meu-ead/app · PHP 8.4

no diretório do projeto

$ cd meu-ead $ dev up ✔ meu-ead servindo https://meu-ead.localhost $ dev exec php app/admin/cli/cron.php $ dev logs -e $ dev down

5. Guia Rápido: Laravel

Criação com suporte automático para migrações, fila em background, Vite e cron:

na máquina

$ dev plugin install laravel $ dev new laravel minha-api ✔ Laravel pronto em https://minha-api.localhost

no diretório do projeto

$ cd minha-api $ dev up ✔ minha-api servindo https://minha-api.localhost ✔ 2 worker(s) de pé (queue:listen e npm run dev) $ dev exec php artisan migrate $ dev worker $ dev open mail

6. Guia Rápido: WordPress

Scaffolding automático com WP-CLI, banco MySQL, chaves criptográficas e wp-cron:

na máquina

$ dev plugin install wordpress $ dev new wordpress meu-site ✔ WordPress pronto em https://meu-site.localhost → painel em https://meu-site.localhost/wp-admin/

no diretório do projeto

$ cd meu-site $ dev up $ dev exec wp plugin list $ dev snapshot antes-do-update $ dev restore antes-do-update
